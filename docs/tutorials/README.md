# Tutorials

Tutorials are learning-oriented. Each one is a complete walkthrough that starts from a known
state and ends with a result you can inspect. Follow them in order; they explain each step as
they go rather than asking you to make design decisions.

- [Your first analysis](first-analysis.md) — build the workspace, open a binary, navigate
  functions, read pseudocode, triage the file, and save a project.
- [Map a raw image](raw-image.md) — map two disconnected file regions as one address space,
  first in the GUI and then from the CLI.

When you are comfortable with the basics, move on to the [how-to guides](../how-to/) for
task-specific recipes and the [reference](../reference/) for exact option lists.
