# Reference

Reference pages are information-oriented. They describe what exists, what it accepts, and what it
returns. They are meant to be searched rather than read end to end.

- [CLI commands](cli.md) — every `re-cli` subcommand, option, and raw-mapping rule.
- [MCP server](mcp-server.md) — launch, protocol methods, all 26 tools, resources, and limits.
- [GUI windows, menus, and shortcuts](gui.md) — every panel, menu, and keyboard binding.
- [Plugin and console scripting](plugin-api.md) — the two Rhai environments and the functions each
  one exposes.
- [Project file and JSONL formats](project-format.md) — the `.slre` SQLite store, its metadata,
  the JSONL record kinds, and merge behavior.
- [Triage report](triage-report.md) — report fields, JSON and Markdown layouts, and size limits.
- [Supported formats and architectures](supported-formats.md) — loaders, architecture names,
  pointer widths, and byte-order defaults.

If you are looking for a procedure instead of a lookup table, use the [how-to guides](../how-to/).
